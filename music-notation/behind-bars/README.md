# Behind Bars — Elaine Gould (Faber Music, 2011)

Scanned reference, split by chapter for GitHub-friendly file sizes.

## Scanning specifications

- **Resolution**: 400 dpi grayscale (do **not** use 1-bit B&W — thin lines, beams, ledger lines, and grace-note slurs lose detail)
- **Format**: PDF with text layer (OCR English text only; music notation stays as image)
- **At scan time**: split double pages → single, auto-deskew, auto-crop black borders
- **Per-chapter file size target**: ≤ 80 MB (GitHub single-file hard limit is 100 MB)

## Filename convention

`<two-digit-chapter>-<kebab-case-title>.pdf` — e.g. `01-ground-rules.pdf`. Lowercase, hyphen-separated.
